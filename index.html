How I build when the architecture is mine

FitTracker

An offline-first workout tracker that records heart rate from a Bluetooth sensor and reports time in each heart-rate zone. I am building it test-first to practise the things large apps need.

  • Ten Swift Package modules on Clean Architecture. Features see only domain protocols, and one composition root wires the real implementations.
  • Core Data behind a repository protocol, with writes on background contexts and contract tests shared by the real and in-memory stores.
  • A parser for Bluetooth Heart Rate Measurement packets, with a simulated source for development.
  • A design system with an accessible zone palette, light and dark, and Dynamic Type.
  • A Vapor back end with JWT authentication and PostgreSQL, sharing an API contract package with the app.
